# Prototypes (development only)

Throwaway design directions for Home and History. Open with `npm run dev`, then `/prototypes/home` and `/prototypes/history` (`?v=resumen` or `?v=diario`; ArrowLeft/ArrowRight switch). Not in the production build.

- **Resumen** — summary first, calm: one big number and a plain sentence, no cards, hairline lists.
- **Diario** — today first, conversational: talking card, big quick actions, Today/Yesterday, timeline history.
